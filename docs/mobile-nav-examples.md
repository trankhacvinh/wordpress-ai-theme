# Mobile Navigation Examples

## Drawer menu

Phù hợp phần lớn website dịch vụ/công ty.

```text
Mobile menu style: drawer
Mobile nav mode: inherit hoặc manual
```

## Fullscreen menu

Phù hợp landing page ít menu nhưng muốn cảm giác hiện đại.

```text
Mobile menu style: fullscreen
Mobile CTA visible: yes
```

## Dropdown menu

Phù hợp website đơn giản, menu ít mục.

```text
Mobile menu style: dropdown
```

## Mobile menu riêng

Dùng khi desktop có nhiều mục nhưng mobile cần rút gọn.

```text
Mobile nav mode: manual

Trang chủ | /
Dịch vụ | /dich-vu
Bảng giá | /bang-gia
Liên hệ | /lien-he
```
