# Responsive Test Checklist

Dùng checklist này sau khi cài zip mới.

## Header desktop

- Logo desktop hiển thị đúng.
- Menu desktop hiển thị đúng nguồn đã chọn: WordPress Menu hoặc Manual Menu.
- Header CTA hiển thị/ẩn theo setting.
- Sticky header bật/tắt đúng.
- Dropdown submenu không bị che.

## Header mobile

Test ở các width:

```text
390px
430px
768px
900px
1024px
```

Kiểm tra:

- Logo mobile hiển thị nếu có cấu hình.
- Nút hamburger hiển thị.
- Mobile menu mở/đóng được.
- Kiểu dropdown/drawer/fullscreen hoạt động đúng.
- Mobile menu riêng hoạt động nếu chọn manual.
- CTA mobile hiển thị/ẩn theo setting.
- Khi mở drawer/fullscreen, body không scroll nền.

## Footer desktop

- Footer columns hiển thị theo cấu hình.
- Link đúng URL.
- Contact/social/copyright đúng.
- Layout columns không vỡ ở desktop.

## Footer mobile

- Footer chuyển về 1 cột ở mobile.
- Text không tràn màn hình.
- Link dễ bấm.
- Khoảng cách đủ rộng.

## Section responsive

- Hero không bị vỡ heading.
- Services/pricing/gallery/portfolio chuyển cột hợp lý.
- Slider hoạt động ở mobile.
- Modal không vượt chiều cao màn hình.
- Lightbox ảnh vừa viewport.
