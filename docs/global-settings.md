# PMEDIA AI Global Settings

Global Settings dùng để chỉnh các phần dùng chung của website mà không cần sửa code theme.

## Menu

Vào:

```text
PMEDIA AI > Global Settings
```

Có thể chỉnh:

- Tên thương hiệu
- Logo desktop
- Logo mobile
- Header layout
- Sticky header
- CTA trên header
- Menu desktop
- Menu mobile riêng
- Kiểu menu mobile: dropdown, drawer, fullscreen
- Footer columns
- Footer contact
- Social links
- Copyright
- Container width
- Custom CSS nâng cao

## Manual menu format

Mỗi dòng một link:

```text
Trang chủ | /
Giới thiệu | /gioi-thieu
Dịch vụ | /dich-vu
Liên hệ | /lien-he
```

## Footer columns format

Dùng `[Tên cột]`, sau đó là các link:

```text
[Công ty]
Giới thiệu | /gioi-thieu
Dịch vụ | /dich-vu

[Hỗ trợ]
Liên hệ | /lien-he
Câu hỏi thường gặp | /cau-hoi-thuong-gap
```

## Responsive

Theme hỗ trợ các kiểu mobile menu:

- `dropdown`: menu xổ xuống dưới header
- `drawer`: menu trượt từ bên phải
- `fullscreen`: menu phủ toàn màn hình

Mobile menu có thể dùng chung menu desktop hoặc dùng menu riêng.
